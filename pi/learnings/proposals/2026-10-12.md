**Evidence:**

- `pi/learnings/proposals/2026-09-14.md`: `"You've hit your session limit · resets 11:10am (America/New_York)\nclaude CLI failed: 1"` — identical pattern, committed and pushed as PR #18.

**Root cause:** `pi/learnings/self-review.sh:130-131` captures Claude's rate-limit error into `$REPORT` and the script then unconditionally commits/pushes/opens a PR regardless of whether the output is a real proposal.

**Patch:** `pi/learnings/self-review.sh:131`

```diff
--- a/pi/learnings/self-review.sh
+++ b/pi/learnings/self-review.sh
@@ -130,6 +130,16 @@ EOF
 REPORT=$(echo "$PROMPT" | /usr/bin/claude -p --model claude-opus-4-7 2>&1 \
   || echo "claude CLI failed: $?")
 
+# Abort if Claude was unusable — otherwise we commit a near-empty proposal and
+# open a PR whose only content is "session limit · resets ...". Exit nonzero so
+# the systemd timer surfaces the failure; next Monday will produce a real one.
+if printf '%s' "$REPORT" | grep -qE 'session limit|claude CLI failed'; then
+  echo "FATAL: claude CLI unusable — skipping proposal + PR for $DATE" >&2
+  if [ -r "$ENV_FILE" ]; then
+    TOPIC=$(grep '^NTFY_TOPIC=' "$ENV_FILE" | cut -d= -f2- | tr -d "'\"")
+    [ -n "${TOPIC:-}" ] && curl -sf -m 10 -H "Title: GHP self-review skipped — Claude rate-limited" -H "Tags: warning" -d "$DATE" "https://ntfy.sh/$TOPIC" >/dev/null || true
+  fi
+  exit 1
+fi
+
 cat > "$OUT_REL" <<EOF
```

**Why safe:** Pure early-exit on a two-string sentinel — on successful Claude runs (every path that doesn't contain "session limit" or "claude CLI failed") control flow is identical to today; the only observable change is that rate-limited runs stop creating stale PRs and instead ntfy-ping + exit nonzero, which is strictly better signal than today's silent garbage-PR behavior.

**Verification:** `REPORT="You've hit your session limit · resets 12:10pm"; printf '%s' "$REPORT" | grep -qE 'session limit|claude CLI failed' && echo "would abort"` prints `would abort`; next week's journal should show no PR URL for any week where Claude was limited, and no `proposals/<date>.md` file should appear on `main` for such weeks.
