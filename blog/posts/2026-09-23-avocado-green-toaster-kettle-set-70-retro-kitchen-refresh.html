Frequently asked

Is an avocado-green toaster and kettle set worth $70, or is it a fad?

Generic retro toaster-and-kettle sets on Amazon run $55-$85 with ratings typically between 4.2 and 4.6 stars. BHG's coverage frames the color as designer-adjacent for 2026, but the appliances themselves are the same commodity hardware as any budget toaster — you're paying for the shell color and shape, not different internals.

Will a plastic retro appliance smell when I first use it?

Reviewers across this category consistently report a plastic odor for the first several uses, which typically fades within a few boils or toasting cycles. It's common across budget small appliances generally, not specific to avocado-colored units.

Does the avocado-green color match exactly across different brands' toasters and kettles?

Only if bought as a matched set from the same listing or manufacturer batch — plastic dye lots vary between production runs, so mixing a toaster from one brand with a kettle from another risks a visible shade mismatch.

What's the cheapest way to extend the retro-green look beyond the counter?

Cabinet and drawer hardware is the lowest-cost extension: Ravinte's 30-pack of matte black pulls runs about $0.90 per pull at $26.99 total, cheaper than repainting or replacing cabinet fronts.
